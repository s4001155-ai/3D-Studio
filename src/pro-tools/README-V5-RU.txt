3D Studio Advanced Tools v5 — экспериментальная браузерная сборка

1. Распакуйте архив и откройте index.html.
2. Вкладка Special Tools содержит только Print Analyzer Pro.
3. Вкладка Pro Tools содержит остальные 9 экспериментальных инструментов.
4. ПКМ по названию инструмента открывает инструкцию.
5. Print Analyzer Pro: Show support suggestions. Красные точки отмечают места, где предыдущий слой не обнаружен.
6. Перемещайте объекты; подсветка пересчитывается. Clear highlights — выключить анализ.

Это прототип: оценка геометрии приближённая и не заменяет проверку в слайсере.
Не используйте экспериментальные версии для единственной копии важных проектов.
