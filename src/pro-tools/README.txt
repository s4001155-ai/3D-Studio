3D Studio — Special & Pro Tools
Распакуйте архив, откройте index.html. Слева выберите Special Tools или Pro Tools. ПКМ по названию — инструкция. Для 3D-моделей нужен интернет (Three.js CDN). В случае ограничений file:// запустите через локальный сервер или GitHub Pages. Это отдельные экспериментальные версии, не готовые профессиональные CAD-инструменты.
