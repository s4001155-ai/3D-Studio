3D Studio — Print Analyzer Pro v6 (эксперимент)

1. Распакуйте архив.
2. Откройте index.html.
3. Выберите Special Tools → Print Analyzer Pro.
4. Создайте фигуры, нажмите Show support suggestions.
5. Сравните: куб на платформе; куб на другом кубе; куб в воздухе; тор с нависанием.

Изменения v6: красные отметки объединяются в участки, проверяется наличие материала на предыдущем слое, учитываются платформа и другие объекты. Алгоритм по-прежнему приблизительный и не является слайсером. Сохраните резервные копии проектов. Интернет нужен для Three.js.

Остальные девять прототипов сохранены в Pro Tools. Код проверен на синтаксис, не проверен в реальном браузере.
