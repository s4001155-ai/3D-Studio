3D Studio Advanced Tools — экспериментальное обновление v4
1. Shell: добавлена кнопка создания сплошного куба (solid box); полая коробка теперь отдельный необязательный режим.
2. Print Analyzer Pro: более строгая проверка контакта с платформой, уменьшен допуск до 0.25 мм; ограничена приблизительная проверка по ограничивающим коробкам только для осевых BoxGeometry.
3. Для проверки тора поднимите его над платформой или поверните так, чтобы появились неподдерживаемые нависания.
Это не анализ слоёв слайсера. Возможны ложные срабатывания и пропуски. STL нужно проверять отдельно.
