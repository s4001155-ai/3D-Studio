3D Studio 5.4.0 Windows Public Beta — исходный проект, не готовый EXE.

1. В Cloudflare Worker 3d-studio-api замените текущий код файлом cloudflare/worker.js.
2. Секрет THINGIVERSE_TOKEN и binding SEARCH_LIMITER должны остаться настроены.
3. Проверить /health, /search?q=car, /download?id=3387810 (для последнего модель может не иметь STL).
4. В GitHub загрузите исходники в корень репозитория и запустите Actions -> Build 3D Studio Windows Public Beta 5.4.0.
5. Скачайте EXE из Artifacts и проверьте поиск и импорт.

Секретный токен в ZIP и EXE не включён. Windows-приложение не просит вводить токен.
Возможность публичного скачивания STL зависит от разрешений и доступности файлов Thingiverse.
Пока не проверена реальная загрузка через облачный Worker и запуск EXE на Windows, это кандидат на бета-релиз, НЕ готовый проверенный публичный релиз.
Для защиты публичного API нужен контроль расхода ресурсов, лимитов Thingiverse, авторских лицензий и мониторинг.
