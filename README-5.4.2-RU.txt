3D Studio 5.4.2 — Windows STL Import FIX (исходники)

ПРОБЛЕМА 5.4.1: перед многокомпонентным импортом приложение запрашивало
один STL через /download. При ошибке одиночной загрузки список деталей
даже не открывался.

ИСПРАВЛЕНИЕ:
- Thingiverse сразу запрашивает список STL /files, показывает окно выбора;
- скачивает каждую выбранную деталь отдельно через /part;
- проверяет все детали до изменения сцены;
- сохраняет исходные размеры и относительные координаты, без
  индивидуального масштабирования до 100 мм;
- до 40 STL на одну публикацию (каждый не более 45 МБ);
- Sketchfab оставлен в прежнем экспериментальном состоянии.

ПЕРЕД ТЕСТОМ: развернуть cloudflare/worker.js в существующий
Cloudflare Worker 3d-studio-api. Секрет и rate limiter остаются в Cloudflare.
Только после этого собрать Windows EXE через GitHub Actions:
Build 3D Studio Windows Public Beta 5.4.2.

ОГРАНИЧЕНИЯ: модель Thingiverse может не иметь STL; STL могут
использовать разные системы координат или единицы; не все скачивания
разрешены провайдером. Физическую печать нужно проверять в слайсере.
Windows EXE и живые ответы Thingiverse в этой среде не проверены.
