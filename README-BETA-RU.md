# 3D Studio 0.5.3 Public Beta — Windows + macOS

Это **исходники для сборки** через GitHub Actions, не готовые установщики.

## Как собрать
1. Загрузите содержимое ZIP в корень отдельной ветки/репозитория GitHub.
2. Actions → **Build 3D Studio 0.5.3 Beta Windows and macOS** → Run workflow.
3. Скачайте два артефакта (Windows и macOS) после успешных зелёных проверок.
4. Проверьте установку и запуск на реальных устройствах.

## Cloud API
- Поиск Thingiverse через `https://3d-studio-api.s4001155.workers.dev/search` (проверен пользователем на Worker 1.4).
- Для **импорта STL** требуется дополнительный облачный маршрут `/download/{thing_id}`, которого **ещё нет в Worker 1.4**. В этой бета-сборке кнопка может вернуть ошибку 404 до его реализации.
- Sketchfab остаётся экспериментальным и может потребовать авторизации.
- Локальный сервер автоматически запускается внутри приложения, но Python пользователю не нужен.
- Токен Thingiverse не включён в исходники и установщики.

## Важные ограничения
- Не публикуйте как стабильный релиз, пока не проверены загрузка STL, лицензии, защита от злоупотреблений, macOS Gatekeeper и подпись приложений.
- macOS dmg без Apple Developer ID может вызывать предупреждения Gatekeeper. Не советуйте пользователям отключать защиту системы.
- Исходники проверены синтаксически; CI-сборки и живой импорт в этой среде не запускались.
