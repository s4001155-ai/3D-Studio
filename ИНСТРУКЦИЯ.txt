Как получить EXE через GitHub без установки Node.js на своём компьютере:
1. Загрузите все файлы из архива в GitHub-репозиторий, включая скрытую папку .github.
2. На GitHub откройте Actions → Build Windows EXE → Run workflow.
3. После успешной сборки откройте запуск и скачайте артефакт 3D-Studio-Windows-EXE.
4. Распакуйте ZIP: внутри должны быть установщик и Portable EXE.
5. Проверьте работу и только после этого опубликуйте файлы в GitHub Releases.
ВНИМАНИЕ: файлы EXE пока не подписаны, Windows может показать предупреждение SmartScreen.
