3D Studio Windows — Alpha 0.3
Полный проект для GitHub, включая рабочий сценарий сборки EXE.

1. Загрузите в корень репозитория все файлы и папку src (с заменой существующих).
2. Убедитесь, что скрытый файл .github/workflows/build-windows.yml обновлён.
3. Удалите старый дублирующий workflow, если он остался.
4. GitHub Actions → Build Windows EXE → Run workflow.
5. Скачайте ZIP из Artifacts после успешной сборки.

Новые функции:
- В основном редакторе добавлена кнопка Special & Pro Tools (Experimental).
- Special Tools: Print Analyzer Pro v6.
- Pro Tools: 9 экспериментальных инструментов.
- Движок Three.js теперь берётся из локального vendor после npm install; интернет для открытия редактора не нужен.
- Версия Shell не менялась: полая коробка остаётся отдельной экспериментальной функцией.

Ограничения:
Это экспериментальная версия. Работа и сборка EXE в Windows ещё не проверены.
Проверяйте экспорт STL в слайсере и сохраняйте резервные копии проектов.
