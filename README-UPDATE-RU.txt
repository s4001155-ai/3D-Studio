3D Studio 0.3.1 Alpha — обновление Windows

Что изменено:
- Windows Setup: ярлык 3D Studio на рабочем столе и в меню «Пуск»; добавлена иконка приложения.
- Pro Tools: 9 экспериментальных инструментов в левом боковом меню, НАД Special Tools.
- Special Tools: Print Analyzer Pro внутри основного редактора (без перехода на другую страницу).
- Appearance & Usability остаётся под инструментами в том же прокручиваемом боковом меню.
- Pro Tools открываются в отдельной панели предварительного просмотра; основной редактор не выгружается. Сцены пока не синхронизируются.
- Изменения в Print Analyzer экспериментальны; это не полноценный слайсер.

Установка обновления на GitHub:
1. Сохраните копию текущей рабочей версии и файлов проектов.
2. Распакуйте ZIP и загрузите содержимое в корень репозитория, заменяя совпадающие файлы.
3. Убедитесь, что папка build/ с icon.ico загружена, а .github/workflows/build-windows.yml обновлён.
4. В Actions → Build Windows EXE нажмите Run workflow.
5. После успеха скачайте 3D-Studio-Windows-Release в Artifacts, распакуйте и запустите Setup EXE.
6. Если программа была установлена раньше, переустановите новую версию, чтобы появился новый ярлык.

Внимание:
Это исходники, не готовый EXE. Сборка и работа в Windows здесь не проверены.
При загрузке через браузер скрытая папка .github может не загружаться: обновите workflow через веб-редактор GitHub.
Не загружайте в репозиторий старый ZIP одновременно с распакованными файлами.
