3D Studio 5.4.1 — Windows Multi-Part Import (исходники)

В Cloudflare Workers заменить код на cloudflare/worker.js и нажать Deploy.
Проверить /health, /files?id=THING_ID и /part?id=THING_ID&file=FILE_ID.
После этого загрузить файлы ZIP в корень репозитория GitHub и запустить
Actions -> Build 3D Studio Windows Public Beta 5.4.1 -> Run workflow.
Установщик появится в Artifacts после успешной сборки.

Импорт Thingiverse: выбор нескольких STL, скачивание всех до добавления в сцену,
отдельный объект на каждый STL, общая координатная система и масштаб.
Не нормализует каждую деталь до 100 мм. Единицы STL предполагаются мм.
Сохраняется исходная ориентация; детали могут оказаться вне платформы.
Если автор разместил детали в отдельных локальных координатах, восстановить
сборку автоматически невозможно — их надо расположить вручную.

Файлы car_body.stl, wheels.stl, axles.stl, mounts.stl — пример имён,
а не включённые в ZIP геометрические модели. Доступность этих файлов
определяется конкретной публикацией Thingiverse.

Проверен синтаксис Python/JS и ZIP, но облачный маршрут и Windows EXE
пока НЕ проверены на реальном компьютере.
