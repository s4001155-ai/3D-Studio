3D Studio 0.4.0 Alpha — macOS (неподписанная тестовая сборка)

Это исходный проект и GitHub Actions, НЕ готовый DMG.
1. Распакуйте ZIP и загрузите его содержимое в корень репозитория GitHub.
2. Проверьте, что .github/workflows/build-macos.yml появился в репозитории.
3. GitHub → Actions → Build macOS App → Run workflow.
4. После успешной сборки скачайте Artifacts: 3D-Studio-macOS-arm64 (M1/M2/M3/M4/Apple Silicon) или 3D-Studio-macOS-x64 (Intel).
5. Распакуйте скачанный артефакт; внутри должен быть DMG и ZIP приложения.
6. Передайте знакомому DMG, соответствующий процессору его Mac.

Это неподписанная и не нотариально заверенная сборка. macOS может блокировать запуск. Не отключайте Gatekeeper глобально. Пользователь Mac должен сам решать, доверяет ли приложению, и использовать штатные настройки безопасности macOS.

Проверка на Mac ещё НЕ проводилась. Отправляйте только как экспериментальную альфа-версию.
