3D Studio 5.3.2 Windows Desktop Test

Это ИСХОДНЫЙ ПРОЕКТ, а не готовый EXE.
Собрать: загрузить содержимое ZIP в корень репозитория GitHub, затем Actions ->
Build 3D Studio Windows Desktop Import Test 5.3.2 -> Run workflow.
Скачать Artifacts -> 3D-Studio-Windows-5.3.2-Desktop-Test.

В приложении открывается полноэкранное/развёрнутое окно, есть кнопка
«Полный экран» и F10. Сохранены инструменты 3D Studio и локальный поиск.
Для Thingiverse вводится свой токен в стартовом окне (только для теста).
Токен передаётся локальному процессу через переменную окружения и не записывается
в файлы. Это НЕ безопасная схема для публичного релиза; не публикуйте токен.
STL: исправлена обработка нескольких файлов, но доступность файлов
Thingiverse и работу импорта на Windows нужно проверить на реальном ПК.

ВАЖНО: текущая Cloudflare API 1.4 поддерживает только поиск, а не загрузку STL.
Поэтому для теста импорта в этой сборке используется локальный Python gateway
с отдельным тестовым токеном. Публичную версию без ввода токена нельзя
считать готовой, пока не реализован и не проверен облачный импорт.
