3D STUDIO 5.3 — WINDOWS RELEASE CANDIDATE (ИСХОДНИК ДЛЯ СБОРКИ)

Внимание: это НЕ готовый EXE. Архив содержит проект для автоматической сборки установщика Windows на GitHub Actions.

ЧТО ВНУТРИ
- Рабочий браузерный интерфейс 3D Studio 5.3.
- Локальный сервер Thingiverse, который автоматически запускается внутри приложения.
- Electron-оболочка для Windows и установщик с ярлыком рабочего стола.
- Входной экран, позволяющий разработчику ввести Thingiverse App Token на время сеанса.
- GitHub Actions workflow для сборки EXE в Windows runner.

КАК ПОЛУЧИТЬ EXE
1. Создайте отдельную ветку/репозиторий или загрузите ВСЕ файлы и папки этого архива в корень репозитория.
   ВАЖНО: папка .github/workflows должна сохранять точную структуру.
2. На GitHub откройте Actions -> Build Windows EXE RC 5.3 -> Run workflow.
3. Дождитесь завершения (зелёная отметка).
4. Откройте результат запуска, внизу скачайте Artifact «3D-Studio-5.3-Windows-RC-installer».
5. Распакуйте Artifact и запустите установщик EXE на Windows.
6. После установки откройте ярлык «3D Studio» на рабочем столе.

ТЕСТОВАЯ АВТОРИЗАЦИЯ
При старте приложение спрашивает Thingiverse App Token. Введите токен в окно приложения; он будет передан только локальному серверу в памяти на время работы.
Без токена Thingiverse поиск недоступен. Sketchfab поиск может работать, но импорт требует авторизации.
Никакой токен не должен храниться в исходниках, GitHub Actions Secrets, репозитории или опубликованном EXE.

ПУБЛИЧНЫЙ РЕЛИЗ
Для публикации пользователям БЕЗ ввода токена нужен отдельный защищённый облачный API-посредник. Нельзя безопасно встроить App Token в EXE. Пока это лишь тестовый Windows Release Candidate.

ОГРАНИЧЕНИЯ
- Сам EXE в этой среде не собирался и на Windows не тестировался.
- Electron и PyInstaller собираются на GitHub Actions; в CI могут потребоваться исправления.
- 3D Studio загружает некоторые библиотеки через CDN; полный офлайн-режим пока не гарантирован.
- Установщик не подписан цифровой подписью, Windows может предупредить о неизвестном издателе. Не отключайте защиту системы.
- Thingiverse и Sketchfab могут ограничивать API и скачивание моделей; печатаемость и масштаб импортированных моделей проверяйте в слайсере.
- Не публикуйте RC как стабильную версию до реального тестирования.
